Kubernetes Node — Requests & Actual Usage fitted view

Both lanes share one scale and the full node = 4 CPU. The top lane packs pods by their request and labels each with its fair share (fs = the slice it would get if every pod competed). The bottom lane packs pods by the CPU they actually get after throttling — so the boxes always fit inside the node. How much a pod wanted and any throttling are shown as text.

Read it like this:  • Empty space at the right of a lane is unused node capacity.  • When throttling is active the bottom lane fills the node exactly — it's saturated.  • A pod whose want ≤ its running CPU isn't throttled (even if it uses more than it requested).  • Raise a pod's request and watch its fs grow and its throttling shrink.
